📖 Cara Dapatkan Deployment ID
  • 1
    Buka Google Sheet → klik Extensions → Apps Script
  • 2
    Dalam Editor, klik Services (+) → tambah Drive API dan Google Docs API
  • 3
    Tampal kod pkj-apps-script.js yang diberi → klik Save
  • 4
    Jalankan fungsi setupAllHeaders sekali sahaja
  • 5
    Klik Deploy → New deployment → Type: Web app
  • 6
    Execute as: Me → Who has access: Anyone → Deploy
  • 7
    Salin Deployment ID → tampal di atas
