📖 Cara Dapatkan Deployment ID
  • 1
    Buka Google Sheet → Extensions → Apps Script
  • 2
    Tampal kod pkj-apps-script.gs → klik Save (💾)
  • 3
    Pilih fungsi setupAllHeaders → klik Run ▶ (sekali sahaja, untuk cipta header)
  • 4
    Klik Deploy → New deployment → Type: Web app
  • 5
    Execute as: Me → Who has access: Anyone → Deploy
  • 6
    Salin Deployment ID (kod AKfycb...) → tampal di atas
